# Швейный маркетплейс

Мобильная платформа и сайт, соединяющие клиентов с портными и швеями
для индивидуального пошива. Условно «профильный Avito / hh» для пошива одежды.

> Командный проект в активной разработке. Этот репозиторий содержит продуктовое
> описание; код ведётся отдельно.

## Проблема

Клиенту негде найти проверенного мастера с портфолио, прозрачной ценой
и безопасной оплатой. Мастеру негде получать клиентов с готовым, понятным запросом.
Рынок разрознен: соцсети, сарафанное радио, отсутствие гарантий по оплате и срокам.

## Целевая аудитория

- **Клиенты** — люди, которым нужен индивидуальный пошив или ремонт одежды
- **Мастера** — портные и швеи, ищущие поток клиентов с оплатой и гарантиями

## MVP

- Эскроу-оплата (деньги замораживаются до подтверждения выполнения)
- Трекер статуса заказа
- Каталог тканей и материалов
- Портфолио и рейтинги мастеров
- AI-генератор ТЗ: превращает фото-референс клиента в понятное техзадание для мастера

## Стек

Мобильное приложение — React Native (Expo, TypeScript), веб — сайт-витрина.
Бэкенд и интеграции платежей/эскроу ведутся отдельно.

## Монетизация

- Комиссия с заказа (5–8%)
- Подписка Pro для мастеров (расширенное портфолио, приоритет в выдаче)

## Моя роль

Продуктовая и аналитическая проработка: описание проблемы и рынка,
целевой аудитории, MVP и его логики, конкурентный анализ, монетизация,
ключевые метрики продукта.

## Статус

В активной разработке (приложение + сайт).
